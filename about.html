About me

Hi, I'm Himanshu.

I'm a beginner backend and frontend development student, currently building real projects to turn tutorials into practical skill. I work on Windows with VS Code as my daily driver, and I learn best by breaking things — then figuring out why they broke.

How I got here

I started with the basics: structuring pages with HTML, styling them with CSS, and slowly working my way into JavaScript. From there I moved into backend development with Node.js, which is where most of my recent debugging battles have happened — npm setup issues, port conflicts, and untangling CommonJS from ES module syntax.

On the frontend side, I recently finished a hotel listing website built with plain HTML, CSS, and JavaScript, wired up to a real API and submitted through GitHub. This site follows the same philosophy: build something real, ship it, and learn from what goes wrong.
